# Antigravity • Web Music Player

Trình phát nhạc cục bộ trên trình duyệt với phong cách không gian viễn tưởng (Antigravity & Cyberpunk).

## 🚀 Cách mở và sử dụng
1. Mở trực tiếp file `index.html` bằng trình duyệt (Chrome, Edge, Brave, Firefox).
2. Nhấp nút **"Mở Thư Mục Nhạc"** để chọn bất kỳ thư mục nào chứa file `.mp3`, `.wav`, `.flac`, `.ogg`, `.m4a` trên máy tính.
3. Hoặc kéo thả trực tiếp thư mục/file nhạc vào giao diện trình duyệt.

## ⌨ Phím tắt (Keyboard Shortcuts)
- `Space`: Phát / Tạm dừng
- `N` / `P`: Bài tiếp theo / Bài trước đó
- `←` / `→`: Tua lùi 5s / Tua tới 5s
- `↑` / `↓`: Tăng / Giảm âm lượng 5%
- `M`: Bật / Tắt tiếng (Mute)
- `S`: Bật / Tắt chế độ xáo bài (Shuffle)
- `L`: Chuyển chế độ lặp (Tắt -> Lặp danh sách -> Lặp 1 bài)
